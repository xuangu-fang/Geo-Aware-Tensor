# 第五轮迭代：The Well 真实数据方法门禁

## 1. 门禁纪律

本轮只用 seed 0、1% observation 和 validation，不读取 test 做方法选择。目的不是
形成性能结论，而是回答两个问题：当前 Paper A/B formulation 是否能利用公共
maze 数据，以及是否值得直接投入 3-seed × 1%/2%/5% pilot。

## 2. Paper A：可分离 operator Tucker

### 2.1 实现改进

公共场的 1% mask 已有约 8,233 个观测。原 CP posterior 为 LOO calibration
构造 `n_obs×n_obs` kernel，真实数据上存在平方内存风险。本轮改为 Bayesian linear
leverage 的解析 LOO，内存降为 `n_obs×rank`，与 Tucker posterior 的校准方式一致。

空间 operator 首版把 64×64 material speed 分别沿 x/y 平均，构造两个一维加权
Laplacian；time/x/y spectral modes 为 40/32/32。Tucker ranks 为 (6,10,10)，
matched CP rank 14，参数量分别 1,480 与 1,470。

### 2.2 结果

| 方法 | observed NRMSE | held-out NRMSE | 参数量 |
|---|---:|---:|---:|
| correct operator Tucker | 0.685 | 1.309 | 1,480 |
| wrong operator Tucker | 0.673 | 1.328 | 1,480 |
| flat operator Tucker | 0.625 | 1.489 | 1,480 |
| correct operator CP | 0.635 | 1.312 | 1,470 |

正确 operator 相对 wrong/flat 有弱方向性，但没有优于 observation-matched CP，且
所有方法 held-out 都差于 zero predictor。训练点显著更好、held-out 更差，说明是
过拟合而不是优化完全失败。

### 2.3 决策

该 formulation **REJECTED**，不进入 3-seed。关键错误是把二维 maze topology
通过轴向平均压成可分离 x/y operator；增加 rank 只会继续拟合观测点。下一版应把
完整 2D material graph 作为一个 spatial mode，张量组织改为
`instance/source × time × graph-spectral-mode`，再比较 Tucker/CP 与 wrong graph。

## 3. Paper B：source-aligned paired phase

### 3.1 数据驱动修正

尝试加载全部 64 train geometry 时发现 trajectory 55 的小源被 stride-4 完全漏掉。
该负信号触发第四轮数据重提取；block mean 后 112/112 源均保留。因此下列结果
全部基于修正版数据，旧 8-case 探索数字作废。

当前模型从 `pressure(t=0)` 的高压环集合构造 material-weighted multi-source 最短
距离；wrong control 使用到源质心的欧氏距离。64 个 train trajectory 提供 1%
观测，评估两个未参与训练的 validation geometry。test 完全未触碰。

### 3.2 结果

| 方法 | validation macro NRMSE | 参数量 |
|---|---:|---:|
| paired phase CP | 0.99228 | 23,040 |
| wrong-distance paired CP | 0.99245 | 23,040 |
| neural CP | 0.99385 | 23,552 |
| joint INR | 0.99412 | 11,713 |

paired CP 在四者中最好，但 correct/wrong 差值只有 0.00016，且整体接近 zero
predictor。它不足以支撑 geometry-aware 因果 claim。

### 3.3 决策

该 formulation **REJECTED**，不进入 3-seed。The Well 初态有 1–6 个环，单个
“到源集合最短距离”会把多个相位前沿压成一个标量，也没有表示每条路径穿过的
阻抗、反射次数与 maze junction。下一版最小改造不是加深 MLP，而是：

1. 使用 2–4 个 source-component distance channels，而不是全源集合 min；
2. 每个 channel 同时提供 travel time 与累计 log-impedance；
3. 将任务改为短 causal window `p(t-k:t)→p(t+1:t+h)`，避免要求 `t=0` 一步预测
   全部 201 个强反射时刻；
4. 仍保留 explicit paired CP contraction，并以 wrong/no path feature 为核心消融。

## 4. 下一轮优先级

- P0-A：完整 2D graph eigenmode + instance/time/spatial Tucker smoke；先验证 correct
  graph 是否明显优于 permuted/flat graph，再考虑 structured factor posterior。
- P0-B：multi-source path-impedance causal paired tensor；先在独立 solver 上控制
  source 数与反射，再迁移 The Well。
- P1 baseline：同一 causal window 下加入 persistence、CP、joint INR、FNO/TFNO；
  在 formulation 通过单 seed 因果门禁前，不启动昂贵 official baseline sweep。

本轮价值是拒绝两个“数值能跑但故事不成立”的版本。Paper A/B 的核心仍是把
传统 Bayesian/tensor factorization 做成几何感知；下一步改变的是能保留几何的
mode/data structure，而不是放弃这个核心。
