# 几何感知张量学习核心技术报告

## 0. 报告定位

本报告统一说明当前两个方向的共同技术核心、各自的数学模型、数据结构、实验设计、baseline 构造、统计协议和已知边界。它不是两篇英文论文的逐句翻译，而是一份面向后续研究与组内审阅的技术底稿。

当前两篇工作的共同命题是：

> 保留传统 CP/Tucker 的显式多线性结构，同时让每个 mode factor 成为定义在相应几何域上的函数，并由该 mode 的算子、边界条件、拓扑或内禀传播距离进行表示和正则化。

这句话包含两个不可缺少的因果条件：

1. 在相同张量结构下，正确几何必须优于错误或被打乱的几何；
2. 在使用相同正确几何时，显式张量分解必须在目标 regime 中优于不含多线性瓶颈的平坦模型。

仅仅把 Laplacian 特征或 geodesic distance 拼接到一个 GP/MLP 输入中，只能证明“几何坐标有用”，不能证明“几何感知张量分解有用”。

## 1. 统一张量对象与数据结构

### 1.1 不允许丢失 mode 语义

对一个 (M) 阶部分观测张量，原始对象始终写为

\[
Y_{i_1,\ldots,i_M},\qquad (i_1,\ldots,i_M)\in\Omega,
\]

其中 \(\Omega\) 是观测 index tuple 的集合。工程实现可以在计算 likelihood 时把观测展开成一维 batch，但每条记录必须保留完整的 mode index tuple；不能把所有 mode 先合成普通 joint coordinate，再声称得到的是张量模型。

数据对象分开保存：

- `values`：完整张量，仅训练 mask 中的值可被优化过程读取；
- `indices`：每个条目的 mode index tuple；
- `mode_coordinates`：各 mode 的坐标；
- `basis/operator metadata`：各 mode 的算子本征函数、本征值、图或边界信息；
- `observed mask`：训练可见位置；
- `held_out mask`：评估位置。

### 1.2 统一 CP/Tucker 形式

Tucker 形式为

\[
\widehat Y_{i_1\ldots i_M}
=\left\langle \mathcal G,
f^{(1)}(x^{(1)}_{i_1})\otimes\cdots\otimes
f^{(M)}(x^{(M)}_{i_M})\right\rangle.
\]

CP 是 Tucker core 为超对角结构时的特例：

\[
\widehat Y_{i_1\ldots i_M}
=\sum_{r=1}^{R}a_r\prod_{m=1}^{M}f^{(m)}_r(x^{(m)}_{i_m}).
\]

几何通过 mode factor 进入：

\[
\mathcal A_m\phi_{mk}=\lambda_{mk}\phi_{mk},\qquad
f^{(m)}(x)=W_m^\top\Phi_m(x).
\]

不同 mode 可以有完全不同的算子和边界条件。例如时间是 Neumann interval，空间 range 是 Dirichlet interval，角度是 circle；把三者统一当成无结构离散 index 会丢掉关键先验。

## 2. Paper A：算子因子上的 Bayesian CP

### 2.1 模型

主模型是显式 Bayesian CP：

\[
Y_{ijk}=\sum_{r=1}^{R}a_r
(\Phi_1u_{1r})_i(\Phi_2u_{2r})_j(\Phi_3u_{3r})_k
+\epsilon_{ijk}.
\]

对 mode \(m\) 的谱系数施加频率依赖先验：

\[
u_{mkr}\sim\mathcal N\!\left(0,(1+\lambda_{mk})^{-p_m}\right).
\]

这等价于对高算子能量成分施加更强 shrinkage。每个完整 mode grid 上的 factor column 被归一化为单位 RMS，消除 CP 的 reciprocal scaling 自由度，由 \(a_r\) 承担分量幅度。

观测 index 上的 CP design 为

\[
Z_{\boldsymbol i r}=\prod_m f^{(m)}_r(i_m).
\]

给定 factor mean，幅度后验可精确计算：

\[
\Sigma_a=(\beta Z_\Omega^\top Z_\Omega+A)^{-1},\qquad
\mu_a=\beta\Sigma_aZ_\Omega^\top y_\Omega.
\]

当前最终版本使用固定 rank 和等 component precision。原先尝试的 Type-II ARD 没有产生有效剪枝，因此不属于最终贡献。

### 2.2 factor uncertainty

仅对幅度 \(a\) 做后验会严重低估 multiplicative factor 的不确定性。当前实现对每个谱 factor coefficient 使用 diagonal Gauss–Newton/Laplace 近似：

\[
v^{-1}_{mkr}\approx(1+\lambda_{mk})^{p_m}
+\beta\sum_{\boldsymbol i\in\Omega}\phi_{mk}(x_{i_m})^2
\left[a_r\prod_{q\ne m}f^{(q)}_r(i_q)\right]^2.
\]

预测方差由三部分组成：

1. conditional amplitude posterior 的 \(Z\Sigma_a Z^\top\)；
2. observation noise；
3. factor coefficient uncertainty 经过 CP product 的一阶 delta propagation。

### 2.3 严格 observation-only calibration

观测集按固定 seed 划分为 75% preliminary-fit 与 25% calibration：

1. preliminary normalization 只由 75% 子集计算；
2. operator-GP initializer、factor fitting 和 preliminary posterior 也只看该 75%；
3. 25% calibration observation 只用于确定一个 95% residual scale；
4. 最终 point model 在全部 observation 上重新拟合；
5. 其 posterior standard deviation 乘以 calibration scale。

Flat operator GP 接受同样 split protocol，并关闭自己的内部 LOO calibration，避免 proposed model 独享校准数据或 baseline 使用不同规则。

### 2.4 为什么需要 operator-posterior → CP-ALS 初始化

极低观测率下，CP 的乘法参数化会产生大量差的局部 basin。随机初始化在 0.5% 下明显失败。当前初始化流程为：

1. 仅用 observation 拟合 dense operator posterior mean；
2. 将 posterior mean reshape 回三阶张量；
3. 对它执行普通 CP-ALS；
4. 把 ALS factor 投影回相应 mode operator basis；
5. 从该点优化原始 Bayesian CP likelihood。

Dense posterior 只用于初始化，最终 predictor 不包含它；其时间被计入总训练时间。正确几何 CP 和错误几何 CP 分别使用各自几何下的 initializer，避免把正确几何信息泄漏给错误几何对照。

## 3. Paper A 的数据与实验设计

### 3.1 主 controlled tensor

张量大小为 `20 × 28 × 36`，mode 为：

| mode | 几何 | basis | 边界/拓扑 |
|---|---|---|---|
| time | interval | 7-frequency Neumann basis | 端点零法向导数 |
| range | bounded interval | 8-frequency Dirichlet basis | 边界值为零 |
| angle | circle | 7-frequency Fourier basis | 周期闭合 |

生成器先构造 rank-4 operator factor tensor，component amplitudes 为 `1.15, -0.80, 0.52, 0.30`。谱系数随频率按约 \(k^{-1.15}\) 衰减。随后加入局部 off-model interaction：

\[
0.13\exp\!\left[-\left(\frac{t-.63}{.12}\right)^2
-\left(\frac{x-.74}{.10}\right)^2\right]\cos(5\theta+4t).
\]

因此数据总体 CP-plausible，但不是 learner 的精确先验抽样。

### 3.2 mask、噪声与统计单位

- 主确认：2% random observation；
- 极端稀疏诊断：0.5% random observation；
- 结构缺失：`periodic_gap`，观测候选排除跨越 circle seam 的连续 25% sector；
- noise：观测值加入相对于观测标准差 10% 的 Gaussian noise；
- 所有模型在同一 seed 下共享 mask 和 noise draw；
- 最终 2% 结果使用未参与选择的 seeds 30–39；
- 每个 seed 是一个独立统计单位，使用 paired bootstrap CI 和 exact paired sign-permutation test。

### 3.3 stress tests

1. **Tucker-format mismatch**：生成 multilinear rank `(4,5,5)` 的 dense-core Tucker tensor。它检验 CP 格式假设，而不是几何本身。
2. **The Well Active Matter**：周期空间物理张量，1% 单 seed stress test。当前没有构造与数据真实机制完全匹配的 obstacle/source geometry，因此不作为主确认。

## 4. Paper A baseline 的构造与因果作用

| baseline | 具体构造 | 控制的问题 |
|---|---|---|
| Wrong-geometry Bayesian CP | 与主模型相同的 rank、优化、posterior 和校准；仅对每个 operator basis 的 grid rows 做固定随机置换 | 正确 topology/boundary 是否真的重要 |
| Discrete Bayesian CP | 每个 mode 使用 identity basis，eigenvalue 全为 0；等价于普通 factor table | operator side information 是否优于无结构 index prior |
| Flat operator GP | 枚举 mode eigenfunction 的 tensor products，按 joint eigenenergy 保留 512 个特征，做 exact feature Bayes | 显式低秩 CP 是否比“同样正确几何的平坦回归”有贡献 |
| Geo-CP without ARD | 最终 fixed-rank 模型 | ARD 是否带来有效 pruning |
| Geo-CP with ARD | conditional amplitude posterior 中做 MacKay-style Type-II updates | 自动秩恢复能否工作；最终为负结果 |
| Random-init Geo-CP | 去掉 operator posterior/ALS warm start | 收益是否只是优化初始化带来的 |

主模型有 256 个 predictive coefficients，flat GP 保留 512 个 product features，discrete CP 有 680 个 factor coefficients。最终实现中 Geo-CP 包含初始化与校准，平均约 8.19 秒/seed；flat GP 约 0.49 秒，因此当前贡献是统计效率和结构解释性，不是训练加速。

## 5. Paper A 的最终证据与边界

### 5.1 2% frozen confirmation

| 模型 | NRMSE | NLL | 95% coverage | 95% width |
|---|---:|---:|---:|---:|
| Geometry Bayesian CP | **0.198±0.037** | **−0.158±0.180** | 0.983±0.011 | 1.080±0.251 |
| Flat operator GP | 0.406±0.031 | 0.387±0.085 | 0.948±0.027 | 1.569±0.230 |
| Wrong-geometry CP | 2.459±0.381 | 2.193±0.137 | 0.977±0.015 | 11.408±2.474 |
| Discrete Bayesian CP | 1.406±0.049 | 29.895±14.615 | 0.265±0.056 | 0.648±0.119 |

相对 flat GP，NRMSE 改善 51.2%，95% CI 为 45.0–57.1%，exact paired \(p=0.00195\)。正确与错误几何的差距说明 geometry 贡献；正确 CP 与正确 flat GP 的差距说明 tensor contribution。

### 5.2 负信号

- 0.5% 下 Geo-CP NRMSE `0.751`，flat GP `0.725`：factor 尚不可辨识，不能声称点预测占优；
- periodic gap 下 Geo-CP `0.805`，flat GP `0.797`：连续未见 sector 不能仅靠低秩外推解决；
- Tucker generator 上 Geo-CP `0.928`，flat GP `0.842`：CP core 过于受限；
- ARD 保留全部 rank 8/12，并造成过度自信；
- Active Matter 点预测未超过最佳 baseline。

这些结果共同支持一个较窄但可信的结论：当数据确实近似 CP 且观测足够辨识 factor 时，operator geometry 和低秩张量结构可以同时产生明显收益。

## 6. Paper B：几何条件化神经 CP/Tucker

### 6.1 基础 conditional tensor model

数据索引为 geometry × time × irregular space：

\[
Y_{gti}=u_{G_g}(x_i,t).
\]

基础 conditional CP 为

\[
\widehat Y(g,t,x)=\sum_{r=1}^{R}w_rG_r(e_g)T_r(t)X_r(x;G_g).
\]

空间 factor 明确依赖几何实例 \(G_g\)，所以这是 conditional tensor factorization，不是把不同 mesh 的 node index 强行对齐。Tucker 版本使用小 core：

\[
\widehat Y=\langle\mathcal C,G(e_g)\otimes T(t)\otimes X(x;G_g)\rangle.
\]

各 factor 由独立 MLP 产生，最后只能通过 CP product 或 Tucker contraction 交互；不存在可以绕过 tensor bottleneck 的 joint residual。

### 6.2 几何特征

- geometry factor 输入 7 维 domain descriptor；
- time factor 输入原始时间与频带相位；
- spatial factor 输入 `(x, y, signed boundary distance, source distance)`；
- correct geometry 使用 graph shortest-path/source geodesic distance；
- wrong geometry 只把它替换为 source 的 Euclidean radius，网络容量不变。

基础 phase bank 使用频带 `7, 13, 19, 27, 37` 的 sine/cosine。

### 6.3 speed-aligned paired-phase CP

对 frequency \(k_b\) 和 candidate speed \(c_j\)，利用

\[
\cos(k_b[d_g-c_jt])=
\cos(k_bd_g)\cos(k_bc_jt)+
\sin(k_bd_g)\sin(k_bc_jt).
\]

模型显式建立四类 CP carrier product：

\[
\cos(k_bd)\cos(kct),\quad
\sin(k_bd)\sin(kct),\quad
\cos(k_bd)\sin(kct),\quad
\sin(k_bd)\cos(kct).
\]

五个 bands、三个 speeds、每组四个 component，共 60 个 phase-paired CP components。每个 component 再乘以独立的 geometry amplitude、time amplitude 和 space amplitude。没有任何网络同时看到 `(distance,time)`，所以 traveling phase 的表达来自显式低秩恒等式，而不是 monolithic MLP。

## 7. Paper B 的数据与实验设计

### 7.1 几何族与 cross-resolution split

- train geometry：6 个 narrow wall-with-door domain；
- unseen test geometry：3 个新的 wall width、position、door location/gap 组合；
- train resolution：24×24；
- test resolution：32×32；
- train times：`0.16, 0.24, 0.32, 0.40`；
- test times：`0.20, 0.28, 0.36`；
- observation ratio：1%；
- noise：相对于每个 field 观测标准差 5%。

每个 domain 先在流体节点上建图，Dijkstra 从固定 source `(-0.72,-0.38)` 计算 shortest-path distance。Geometry metadata 可以使用完整已知 domain，但 dense target 只用于 evaluation。

### 7.2 最终 harmonic generator

最终主数据由独立 analytic/eikonal generator 产生：

\[
u_g(x,t)=\sum_{b=1}^{3}A_b(e_g)e^{-\nu_bt}
\cos(k_bd_g(x,s)+\varphi_b)+0.06r_g(x,t).
\]

其中：

- 三个主频为 `7, 13, 19`；
- decay 为 `0.45, 1.05, 1.8`；
- phase offset 为 `0.2, -0.55, 0.8`；
- amplitude 是 geometry descriptor 的固定解析函数；
- \(r_g(x,t)\) 是局部移动 wavepacket，不属于主 rank-3 standing harmonic 结构。

因此该任务的主物理结构低秩，但保留 6% off-model 成分，避免 learner 与 simulator 完全同构。

### 7.3 harder moving-envelope boundary task

另一个 generator 使用两个沿 geodesic distance 移动的 Gaussian wavepacket。它具有明显 time–space envelope coupling，不再是紧凑 CP/Tucker 易于表达的对象。这个 setting 在 2%、24→32 上作为 scope test：它不是被删除的失败，而是用来回答“何时低秩 tensor bottleneck 不应该占优”。

### 7.4 评估指标

- unseen-geometry NRMSE；
- boundary NRMSE；
- shadow-region NRMSE；
- graph eigenbasis 中的 absolute high-band NRMSE；
- 参数量与训练时间。

一个 seed 内含多个 geometry/time task，先对 task 聚合，再以 seed 为统计单位，避免把同一训练 run 里的 nested tasks 当独立样本。

## 8. Paper B baseline 的构造与因果作用

| baseline | 具体构造 | 控制的问题 |
|---|---|---|
| Ordinary geometry-aware CP | geometry/time/intrinsic-space 三个 factor MLP，rank 32，普通 CP contraction | paired phase identity 是否超出一般 geometry CP |
| Plain conditional Tucker | ranks `(5,8,12)`，dense Tucker core | 非对角 cross-mode interaction 是否足够；CP 是否过硬 |
| Diagonal Tucker | 同样参数存储，但只启用 core 对角项 | dense core interaction 的作用 |
| Wrong paired CP | 与 paired CP 完全相同，唯一变化是 geodesic distance → Euclidean radius | 正确传播几何的作用 |
| Raw F-INR-style Tucker | 同 mode grouping/core，但不给 intrinsic phase，只用 raw coordinate/SDF/radius | geometry-aware factor 相对普通 functional tensorization 的作用 |
| No-phase tensor | 保留 tensor 架构，移除 sine/cos phase bank | phase representation 本身的作用 |
| IP-NF | 把 geometry、time、space 与 joint traveling phase 拼接进一个 MLP；无 tensor contraction | 显式 tensor bottleneck 是否优于强 geometry-aware flat model |
| Raw Neural-CP | 按 raw x/y/context 分解，无 geodesic phase | 普通 neural low-rank baseline |
| SIREN | 对 joint coordinate/context 的周期激活 MLP | 强高频 coordinate baseline |

离散 CP/Tucker 无法为完全 unseen geometry index 和新 mesh node 自动生成 factor rows，因此没有人为给它一个不诚实的 zero-shot 数字；对应的适用 baseline 是 raw functional tensor factorization。

## 9. Paper B 的最终证据与边界

### 9.1 1% frozen confirmation

| 模型 | 参数量 | unseen NRMSE | high-band NRMSE |
|---|---:|---:|---:|
| Speed-aligned geometry CP | 16,656 | **0.0952±0.0144** | **0.00404±0.00092** |
| Ordinary geometry CP | 20,992 | 0.1113±0.0213 | 0.00497±0.00113 |
| IP-NF | 7,617 | 0.1825±0.0173 | 0.00728±0.00122 |
| Wrong paired CP | 16,656 | 1.5598±0.1827 | 0.08799±0.01176 |
| Raw F-INR Tucker | 15,545 | 1.8167±0.2535 | 0.06079±0.00217 |
| SIREN | 5,057 | 1.0944±0.0366 | 0.05938±0.00318 |

相对 ordinary geometry CP，NRMSE 改善 14.5%，CI 为 3.4–23.8%，exact paired \(p=0.0391\)。相对 IP-NF 改善 47.9%，\(p=0.00195\)。Correct paired 与 wrong paired 的差距同时验证 geometry effect。

### 9.2 负信号

在 harder moving-envelope task 上：

- conditional Tucker：`0.713`；
- ordinary geometry CP：`0.721`；
- IP-NF：`0.615`；
- wrong geometry tensor：`1.414`。

正确几何仍有贡献，但 tensor bottleneck 不如 joint model。固定 paired CP 在该任务上也只有 `0.818`。结论是：几何感知 tensor 对近似 multilinear 的物理场具有样本效率优势，但不是任意移动局部结构的通用替代。

## 10. 共同实验纪律

1. 同一 seed 内所有模型共享 observation mask 与 noise；
2. geometry basis、graph、distance 可以使用完整 domain，但不能读取未观测 target；
3. pilot seed 用于 redesign，最终确认必须使用新 seed；
4. wrong-geometry control 尽可能与 correct model 同参数、同初始化；
5. task 先在 seed 内聚合，统计只在 seed 间进行；
6. 报告负结果，不通过增大模型或挑 seed 掩盖失败；
7. baseline 的存在必须对应一个明确的因果问题，而不只是“表格更大”。

## 12. 用户反馈后的方法升级

Paper A 已从单一 Bayesian CP 升级为算子几何 CP/Tucker family。新增 operator Bayesian Tucker 在 2% Tucker truth、十个新 seed 上达到 `0.125±0.015` NRMSE，相比 Geo-CP `0.367±0.055` 和 flat operator GP `0.612±0.028` 分别改善 65.9% 和 79.6%。1% 下采用 `(3,4,4)` 小 core 与短程 factor refinement，达到 `0.676±0.072`，相对 flat GP 改善 10.2%。

Paper B 的 phase-envelope 经过 learned rank-Q 和 fixed-RBF Tucker 两种实现后，均未稳定超过 IP-NF，因此没有修改主方法声明。两篇现共享 format mismatch × observation ratio phase diagram、数据协议和 baseline discipline。完整三轮记录与统计见[三轮持续迭代记录](三轮持续迭代记录.md)和[统计汇总](../longterm_results/TABLES.md)。
