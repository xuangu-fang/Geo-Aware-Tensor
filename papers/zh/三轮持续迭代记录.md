# 用户反馈后的三轮持续迭代记录

## 0. 冻结的研究决策

本轮按照审阅反馈固定三项原则：

1. Paper A 的中心从 Bayesian CP 收窄/提升为**算子几何张量分解**，CP 与 Tucker 都是该框架的显式 core 特例；
2. Paper B 的 phase-envelope 只有稳定且显著超过 IP-NF 时才进入主方法；
3. A/B 保持两篇独立主线，但共享 approximation-error × observation-ratio phase diagram、数据划分和 baseline discipline。

隔离环境使用项目内 `.python-packages`，PyTorch 2.8.0+cu128 已在 A100 上验证。改动前 11 项测试通过，新增模型测试后为 14 项通过。

## 1. 第 1 轮：补足表示能力

### 1.1 Paper A：operator-spectral Bayesian Tucker

新增模型

\[
\widehat{Y}_{ijk}=\sum_{a=1}^{R_1}\sum_{b=1}^{R_2}\sum_{c=1}^{R_3}
G_{abc}F^{(1)}_{ia}F^{(2)}_{jb}F^{(3)}_{kc},
\qquad F^{(m)}=\Phi_m U_m,
\]

并继续对每个 mode coefficient 使用算子 Sobolev precision。条件于 mode factors，小 core 使用精确 Gaussian posterior。初始化采用“flat operator posterior → operator-projected HOSVD → core ridge solve”，没有把 dense initializer 留在最终 predictor 中。

首个 Tucker-mismatch pilot（2%、seed 0）为：

| 模型 | NRMSE |
|---|---:|
| Geo Bayesian Tucker | **0.118** |
| Geo Bayesian CP | 0.483 |
| Flat operator GP | 0.619 |
| Wrong-geometry Tucker | 1.535 |
| Discrete Tucker | 1.827 |

在原 CP truth 上，Geo-Tucker 为 0.179，Geo-CP 为 0.280、flat GP 为 0.399，说明 dense core 没有以明显牺牲 CP regime 为代价。

### 1.2 Paper B：learned low-rank phase-envelope

在 paired phase carrier 外增加显式可分 envelope：

\[
E_b(d,t)=1+\sum_{q=1}^{Q}w_{bq}E_q^{(d)}(d)E_q^{(t)}(t).
\]

任何网络都不能同时读取 \((d,t)\)。首轮扫描 `Q=1,2,4,8`；单 seed 中 `Q=2` 把 moving-envelope NRMSE 从 paired CP 的 0.857 降至 0.565，并一度优于 IP-NF 0.654。但更大的 Q 没有单调收益，首先暴露出过拟合与初始化敏感性。

## 2. 第 2 轮：容量、优化与公平性修正

### 2.1 Paper A：观测约束下的小 core

在 1% 观测时，`(4,5,5)` core 加 mode coefficients 的自由度已经接近观测数，长程 factor refinement 会把 NRMSE 推到 0.922。最小修正是：

- multilinear rank 从 `(4,5,5)` 降到 `(3,4,4)`；
- operator regularization 从 0.002 提高到 0.05；
- factor refinement 从 700 steps 缩短到 100 steps；
- core posterior 仍使用全部 observation，test mask 不参与选择。

selection seed 上 NRMSE 从 0.922 降到 0.675，优于 flat GP 0.762。这个结果说明低观测率下关键不是继续扩大 core，而是让有效自由度小于可用于识别它的观测数。

### 2.2 Paper B：严格嵌套和初始化公平

发现旧 runner 会在改变模型列表或 Q 时改变后续 baseline 的随机初值。现已改为每个模型在构造前独立重置同一 seed，correct/wrong 同构模型从完全相同权重开始。

同时把 envelope core 零初始化，使所有 Q 模型严格从 paired CP 开始，再学习低秩调制。三 seed 结果为：

| 模型 | moving-envelope unseen NRMSE |
|---|---:|
| Learned envelope Q=2 | 0.644±0.118 |
| Paired CP | 0.897±0.033 |
| IP-NF | **0.624±0.027** |

结论：相对 paired CP 的改善很大，但尚不能证明优于强 joint baseline。

## 3. 第 3 轮：替代 envelope、冻结确认和 phase diagram

### 3.1 Paper B 的固定 RBF envelope Tucker

为排除 learned factor 的乘法优化问题，进一步实现固定 distance/time RBF factors 和显式 `component × distance-basis × time-basis` 小 core：

\[
E_b(d,t)=1+\sum_{p,q}C_{bpq}\psi_p(d)\eta_q(t).
\]

该版本仍没有 joint MLP，但三 seed NRMSE 为 0.684±0.088，仍差于 IP-NF 0.624±0.027。因此按预先约定的门槛，**phase-envelope 不进入 Paper B 主方法**；代码和负结果保留，避免重复探索。Paper B 继续以已确认的 harmonic/aligned regime 和 paired-phase tensor 为主线。

### 3.2 Paper A 的十个新 seed

冻结配置后使用 seeds 10–19，一次性确认：

| 观测率 | Geo-BTucker | Geo-CP | Flat GP | Wrong BTucker | Discrete BTucker |
|---:|---:|---:|---:|---:|---:|
| 1% | **0.676±0.072** | 0.809±0.072 | 0.752±0.030 | 1.462±0.097 | — |
| 2% | **0.125±0.015** | 0.367±0.055 | 0.612±0.028 | 1.712±0.201 | 1.976±0.131 |

1% 时相对 flat GP 改善 10.2%，paired permutation `p=0.0195`。2% 时相对 Geo-CP 改善 65.9%、相对 flat GP 改善 79.6%、相对 wrong geometry 改善 92.7%，三项 `p=0.00195`。

因此 Paper A 可以支持更强但仍精确的结论：**当 multilinear core 结构与观测数匹配时，正确 mode operators 与显式 Tucker sharing 能同时降低估计误差和 CP 格式误差。**

### 3.3 共享 phase diagram

两条线都新增连续 mismatch generator：

- A：CP-plausible truth 与独立 dense-core Tucker truth 的归一化混合；
- B：geodesic harmonic 与 moving wavepacket 的连续混合。

A 使用 observation ratio 1%/2% 和 mismatch `0,.25,.5,.75,1`；B 使用 0.5%/1%/2% 和 mismatch `0,.5,1`。phase diagram 不用于重新选择最终 seed，而用于定位 tensor bottleneck 的适用边界。图与逐格数值位于：

- [Paper A phase diagram](../longterm_results/phase_a.png)
- [Paper B phase diagram](../longterm_results/phase_b.png)
- [完整 JSON](../longterm_results/summary.json)

最重要的机制结论不是误差随 mismatch 单调变化，而是中间混合会把两个低秩子空间相加，暂时产生比任一端点更高的有效 multilinear rank；这正是 approximation error 与 observation-limited estimation error 的交互。

## 4. 最终去留决策

- **保留并升级 A：** operator Bayesian Tucker 成为 Paper A 主模型；CP 作为 diagonal-core 特例与重要 baseline。
- **不升级 B envelope：** learned CP envelope 和 RBF Tucker envelope 都作为负结果；主方法仍是 speed-aligned paired geometry CP。
- **保留共享实验母题：** 两篇共享 mismatch × observation phase diagram、correct/wrong geometry、flat/joint baseline、独立 seed 和统一统计单位。
- **下一项真正有价值的外部验证：** 冻结当前配置后，用独立 wave/Helmholtz solver 生成多几何数据，而不是继续增加网络组件。
