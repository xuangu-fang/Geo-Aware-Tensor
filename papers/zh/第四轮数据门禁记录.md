# 第四轮迭代：独立与公共数据门禁

## 1. 本轮目标

前三轮的主要风险不是“合成结果不够好”，而是 simulator 与 learner 共享
表示后，几何感知收益可能来自同源偏置。因此第四轮先暂停模型 sweep，建立
两条独立证据链：完全独立的波动求解器和公开的 The Well acoustic maze。
两份数据共享字段、mask 和 baseline 纪律，但 Paper A/B 仍保持独立主线。

## 2. 独立波动数据：两次实质迭代

### 2.1 首版与负信号

首版生成 8 个障碍几何、2 个源、24/32 两种分辨率，共 32 case。有限差分
求解器不 import 任何 tensor、feature 或 learner 代码，并把 target field 与
geometry operator、material operator、source、坐标分别存盘。

数值检查全部通过，但首张末帧图主要显示源附近的入射波：记录只到 `t=0.8`，
而源到障碍物的传播时间约为 `0.8--1.0`。这个结果只能证明“数据能生成”，
不能证明目标真的依赖几何，因此不允许晋级。

### 2.2 修正版与门禁结果

记录窗口扩展为 40 帧、`t=0..2.0`，使透射和反射明确进入目标。修正版结果：

- 32/32 field 有限且非退化；
- source 全部位于 fluid domain；
- operator 最大对称误差为 0；
- 最小数值特征值为 `-1.62e-6`，在 PSD 容差 `1e-5` 内；
- `t≥1` 的场能量占 50.1%–51.1%；
- 重复生成的逐 case SHA-256 完全一致。

数据状态由 IDEA 晋级为 SMOKE。geometry-disjoint split 固定为 5/1/2 个几何，
24 分辨率只用于选择，32 只用于冻结配置后的 resolution transfer。它尚未晋级
PILOT：下一步必须扩大 geometry family，避免在 8 个 geometry 上选模型。

## 3. The Well acoustic maze：公共数据门禁

### 3.1 元数据与成本事实

数据固定到 Hub revision
`8df383a3223f40f7ce66fe77b4ff4d7006dbc272`，license 为 CC-BY-4.0。
实际文件为 20 个 HDF5 LFS shard，每 shard 100 trajectory；HDF5 shape 是
`100×202×256×256` pressure，而官方文字说明写 201 帧。完整 LFS 总量为
319.6GB，固定 train/validation/test 三个完整 shard 仍需 47.9GB。

Hugging Face Dataset Viewer 不支持这些 HDF5 文件，这是本轮负信号。我们没有
因此下载全量，而是验证 LFS HTTP range-read：用 `fsspec+h5py` 直接读取 HDF5
元数据和指定 trajectory/time slice，避免整 shard 落盘。

### 3.2 八轨迹预训练门禁

训练前固定读取 4 train、2 validation、2 test trajectory，每个只抽 6 个时刻并
stride-4 到 64×64。门禁结果：

- 8/8 pressure 有限；
- 8 个 density 几何 SHA-256 全部不同；
- maze wall fraction 为 56.2%–62.2%；
- `pressure(t=0)` 可恢复 3–5 个连接的高压源环组件；
- 重复 range extraction 的本地 NPZ SHA-256 一致。

因此 source 不需要从未来 target 反推。输入契约固定为 density、speed of sound、
`pressure(t=0)`、coordinates 和 query time；target 只能是 `pressure(t>0)`，未来
pressure 与 target-time velocity 禁止参与 geometry/source feature 构造。

### 3.3 固定 pilot 协议

公开 pilot 固定 64/16/32 trajectory，分别来自官方 train/valid/test shard；空间
固定为 64×64。标准整 shard 下载成本过高，默认使用 range extraction，预估本地
pressure 加静态几何约 0.4GB。test 不参与超参数选择；128/256 分辨率实验必须另立
experiment ID，不能回头改变 pilot 配置。

### 3.4 完整 pilot 提取

固定 64/16/32 subset 已通过 range-read 完整提取：112/112 trajectory，最终合计
374,816,800 bytes。loader 将 `pressure(t=0)` 与 `pressure(t>0)` 物理分离，三个
split 严格来自三个官方 shard。seed 0、1% mask 的 sanity 结果为 zero 1.000、
persistence 1.989、observed-mean 0.991；这证明 metric 有方向且复制初态无效，
但不作为方法性能证据。数据状态由 SMOKE 晋级 PILOT。

全量 Paper B harness 随后发现 trajectory 55 的小源被 stride-4 点采样完全漏掉，
于是数据 issue 被重开。最终协议将所有连续 field 改为 4×4 block mean 并重提取；
112/112 `pressure(t=0)` 均为非零，源 abs max 为 2.58–7.74。此次负信号说明
8-case 可视 gate 不足以覆盖小源边缘情况，因此 source audit 被提升为全 subset
promotion 条件。

## 4. 对两篇论文的含义

- Paper A 获得独立 operator geometry 数据，可以检验 correct/wrong/no operator、
  observation-matched Tucker core 和 structured posterior，而不依赖原解析生成器。
- Paper B 获得真正 trajectory-varying maze geometry、显式 source IC 和强散射目标，
  适合 unseen geometry、低 observation ratio 与跨分辨率实验。
- 两篇共享相同 split/mask/metric，但 A 的核心因果问题仍是 operator-aware Bayesian
  Tucker，B 的核心因果问题仍是 geometry/phase-aligned functional tensor。

## 5. 下一轮进入条件

先做一个 seed 的 loader、mask 和 metric sanity check；然后仅用 3 个 selection seeds
比较最小 baseline 集合。若正确/错误几何无差异，或收益只来自参数量，则停止方法
扩增，回到 operator/source 表示诊断。任何 10-seed confirmation 必须在配置冻结后
使用全新 seed，不能把本轮八轨迹门禁样本当成性能证据。
