# 下一步研究路线讨论稿

本文是一份供审阅的研究决策稿。目标是根据当前实验的正、负信号，找出最小但最有辨识力的下一轮改动。核心问题始终是：**如何把传统贝叶斯张量/张量分解真正做成几何感知，并证明几何结构降低了低观测率下的估计难度，而不是仅靠更大的模型容量取胜。**

## 1. 当前证据应如何解读

### 1.1 Paper A 的信号

正信号：

- 在 2% 随机观测下，正确算子几何的 Geo-BCP 明显优于 flat、wrong-geometry 和 discrete CP；最终确认实验的归一化 RMSE 分别约为 0.198、0.406、2.459 和 1.406。
- 正确几何同时改善点预测和 NLL，说明算子谱先验在低样本区间提供了有效的贝叶斯归纳偏置。
- “算子 GP 后验均值 → CP-ALS”初始化是必要且可解释的：它先恢复一个平滑全张量估计，再投影到低秩张量流形。
- 因子后验在部分设置下改善不确定性，证明“贝叶斯化因子”并非无效，只是当前近似仍不稳定。

负信号：

- 0.5% 观测时，正确几何只能做到近似持平，说明先验不能替代低秩因子的可辨识性。
- 对 Tucker 型失配、长条缺口和 Active Matter 公共数据，当前 CP 形式没有稳定优势；这是表示误差，不只是优化误差。
- 对角 Laplace 忽略 CP 的缩放、置换耦合，校准依赖较大的 held-out calibration split。
- 当前 ARD 没有形成可信的秩选择；它更像不稳定后处理，而不是方法贡献。
- 强初始化计算成本高，也会削弱“端到端贝叶斯张量学习”的叙事。

### 1.2 Paper B 的信号

正信号：

- 在相位可对齐、只有 6% 非可分残差的传播场上，1% 观测时 paired phase tensor 达到约 0.095 RMSE，优于普通 Geo-CP 0.111、IP-NF 0.182、错误几何 1.560 和 raw F-INR 1.817。
- 正确/错误几何之间的大差距说明优势不是单纯来自容量，而来自传播距离和相位的正确参数化。
- 模型保留显式张量因子，可检查每个维度、相位对和残差的作用，不把结构藏进联合 MLP。

负信号：

- 在移动包络数据上，IP-NF 约 0.615，而 Tucker、CP、paired tensor 分别约 0.713、0.721、0.818。当前相位配对只能表示载波，不能表示沿传播路径移动的包络。
- learned gates 没有产生稳定成分选择，说明直接对高度相关的相位分量做稀疏化并不可靠。
- 跨分辨率优势目前只在受控生成数据上成立，缺少独立 PDE 求解器产生的数据。
- 当前已知源点和测地距离，几何输入相对理想化；真实场景中源位置、边界或传播度量可能有误差。

### 1.3 一个统一的解释

当前结果可以用“表示误差—估计误差”分解来理解：

\[
\text{test error}\approx
\underbrace{\text{tensor format approximation error}}_{\text{模型能否表示真值}}+
\underbrace{\text{finite-observation estimation error}}_{\text{稀疏观测能否识别因子}}+
\underbrace{\text{geometry mismatch error}}_{\text{几何先验是否正确}}.
\]

几何感知主要降低后两项，但不能修复第一项。当真值接近 CP、Tucker 或可分的相位—包络结构时，几何先验能显著降低样本复杂度；当真值远离所选张量格式时，更强先验甚至会把模型推向错误低维子空间。这解释了正、负结果为何可以同时成立，也给出了下一轮实验主轴。

## 2. 方法方向 A：贝叶斯几何张量

### A1. 算子谱 Bayesian Tucker：最高优先级

**研究问题。** Paper A 的失败究竟来自 CP 格式过窄，还是来自贝叶斯推断本身？

建议把 CP 扩展为一个仍然很小、完全显式的算子谱 Tucker：

\[
\mathcal X=\mathcal G\times_1 U^{(1)}\times_2 U^{(2)}\times_3 U^{(3)},
\qquad
u^{(m)}_k\sim\mathcal N\!\left(0,(L_m+\tau_m I)^{-p_m}\right).
\]

每个模式因子继续受对应几何算子约束，小核心 \(\mathcal G\) 使用高斯后验或结构化收缩。首轮可固定为如 \((6,8,8)\) 的小秩，不引入深网；随后才考虑对 core slice 做 group shrinkage。

它直接回应 Tucker mismatch 的负结果，同时保留“传统贝叶斯张量被几何化”的核心创新。若它在 CP 真值上不损失太多、在 Tucker 真值上恢复优势，就能把 Paper A 从 CP 特例提升为算子感知的多线性贝叶斯框架。

最小决定性实验：

- 数据只用现有 CP 真值和 Tucker mismatch 两组。
- 观测率用 0.5%、1%、2%、5%。
- 比较 Geo-CP、Geo-Tucker、flat Tucker、wrong-geometry Tucker、oracle Tucker 和参数量匹配的 INR。
- 主指标为全域 RMSE；次指标为 NLL、90% coverage/width、参数量和运行时间。

成功判据：Geo-Tucker 在 Tucker mismatch 上相对 Geo-CP 至少降低 15% RMSE，同时在 CP 真值上的退化不超过 5%；correct/wrong geometry 差距仍显著。若只靠增大 core 获益，而 correct/wrong 几何几乎相同，则不能称为几何贡献。

主要风险：core 增加旋转不辨识性。首轮应固定谱白化、正交化 mode factors 并限制 core 尺寸，而不是立即设计复杂变分推断。

### A2. 规范固定后的结构化后验，而非对角 Laplace

**研究问题。** 当前 UQ 不稳，是贝叶斯因子思路错误，还是 CP 的 gauge symmetry 破坏了局部高斯近似？

建议先处理不辨识性，再升级后验：

- 用算子先验白化坐标 \(u=K^{1/2}z\)，在 \(z\) 空间优化和近似后验。
- 每轮对因子做单位 RMS 归一化，把总体幅值集中到单独 component scale。
- 对同一 mode/component 的系数使用 block Gauss–Newton、低秩加对角协方差或 matrix-normal 后验，而不是全局对角 Hessian。
- 对 component scale 使用 group horseshoe 或 half-Cauchy；只有整个 rank-one 成分能量收缩时才称为秩选择。

最小决定性实验：只在现有 2% CP 数据上比较 MAP、对角 Laplace、规范固定的 block posterior；预测均值尽量保持一致，只看 NLL、coverage-width 曲线和 seed 方差。

成功判据：不扩大 calibration split 时，90% 区间覆盖率进入 87%–93%，区间宽度不比当前方法增加超过 20%，且至少 8/10 个 seed 满足。若均值改善但校准不改善，应将其归类为优化改动而非贝叶斯贡献。

### A3. Cross-fit / conformalized Bayesian calibration

**研究问题。** 能否在极低观测率下减少 25% calibration split 的样本浪费？

建议使用仅在已观测条目内部进行的 K-fold cross-fitting：每折拟合后验尺度，最后合并预测；或者对 Bayesian posterior interval 做轻量 conformal 校准。它不改变主模型，价值在于让所有稀缺观测都能参与训练，同时保持 test mask 隔离。

成功判据应同时报告 coverage 和 width，不能仅追求覆盖率。重点测试 0.25%、0.5%、1%，并把“使用了多少独立观测训练最终均值”列入表格。

这一方向实用，但不应先于 A1。否则可能把表示错误的模型校准得很好，却没有改善重建。

### A4. 降低初始化成本

可尝试谱 HOSVD、从高观测率到低观测率的 continuation 或 amortized warm start，替换全量 operator-GP reconstruction。但这是工程优先级，不是核心科学问题。只有在 A1/A2 的方法形态稳定后再做，否则会把“模型失败”和“初始化失败”混在一起。

## 3. 方法方向 B：几何相位张量

### B1. 显式相位—包络低秩张量：最高优先级

**研究问题。** 能否在不退回联合 MLP 的情况下表示沿测地路径移动的非可分包络？

当前 paired tensor 可表示 \(\cos(kd-\omega t)\) 一类载波，但移动包络 \(a(d-vt)\) 对 \(d,t\) 并不 rank-1。最小扩展是给包络一个小的二维低秩结构：

\[
u(g,t,x)=\sum_{b=1}^{B}A_b^{(g)}(g)A_b^{(x)}(x)
\left[\sum_{q=1}^{Q}E_{bq}^{(d)}(d_g(x))E_{bq}^{(t)}(t)\right]
C_b(k_b d_g(x)-\omega_b t).
\]

其中 \(Q\) 是包络秩，首轮只扫 \(Q\in\{1,2,4,8\}\)。也可以把 \(E(d,t)\) 写成很小的 RBF Tucker core，但不能让无限制的 joint \((d,t)\) MLP 接管全部预测，否则会丢失显式张量故事。

最小决定性实验：复用当前 harmonic 和 moving-envelope 生成器，在相同参数预算下比较 paired、phase-envelope、Tucker、IP-NF 和 wrong-geometry。固定其他训练细节，仅改变 \(Q\)。

成功判据：在 moving-envelope 上至少追平 IP-NF，并在 harmonic 上维持当前优势；所需 \(Q\le4\)，且 correct/wrong geometry 差距仍存在。如果只有 \(Q=8\) 或更大才有效，并且模型退化为通用二维函数逼近器，则应诚实地定位为 Tucker 扩展，而不是强物理对齐。

### B2. 受控的“低秩主体 + 小残差”

更一般的公式是

\[
u=u_{\text{geo-tensor}}+\rho r_{\text{joint}},
\]

但必须防止 residual bypass：

- 限制残差参数量和频谱带宽；
- 对 \(r_{\text{joint}}\) 的训练能量或输出范数设上限；
- 尽可能让残差与当前张量切空间正交；
- 单独报告 \(\|r\|^2/\|u\|^2\) 和去掉残差后的性能。

成功判据：残差能量低于总能量的 10%–20%，正确几何消融仍明显优于错误几何，并在 moving-envelope 上超过参数匹配的 IP-NF。若残差吸收大部分能量，这个模型只能叫 geometry-conditioned INR，不能作为几何张量的核心证据。

这个方向比 B1 灵活，也更危险。建议作为 B1 失败后的保底方案。

### B3. 从已知测地距离到可学习传播度量

可学习各向异性的边代价或 eikonal metric，再计算 soft shortest path / differentiable travel time。为避免 target leakage，度量只能从几何、材料系数、边界条件或多个训练实例中学习，不能从同一稀疏目标场直接自由拟合。

该方向扩展应用范围，但会同时引入 inverse problem 和 metric learning 两个新问题。建议在方法主体跑通后再做。最小比较必须包括 known geodesic、Euclidean、learned metric 和 deliberately wrong metric，并测试源位置误差。

### B4. 更一般的几何对应：功能映射或谱子空间

若未来数据没有一致网格点对应，可用 heat-kernel signature、commute-time coordinate、functional maps 或拉普拉斯谱投影建立跨几何坐标。应使用谱子空间/projector，而不是直接依赖单个特征向量的符号与次序，因为重复特征值会导致任意旋转。

这是从“同拓扑不同形变”走向一般多几何数据的关键，但不适合与 B1 同轮引入。

## 4. 数据构造方向

### D1. 建立表示难度 × 观测率的二维 phase diagram

这是最推荐的共享实验。横轴控制张量格式失配，例如：

- 非可分残差强度 \(\epsilon\in\{0,0.05,0.1,0.2,0.4\}\)；
- 或移动包络耦合/速度；
- 或 Tucker core 的非对角能量比例。

纵轴使用观测率 \(\{0.25\%,0.5\%,1\%,2\%,5\%\}\)，在若干切片中再加入几何误差强度。最终主图不只回答“谁平均最好”，而是给出：**在多大的格式失配、多少观测下，几何感知张量仍然优于通用 INR？**

这张图能把当前正负结果统一为一个机制故事，并防止只挑有利数据。若论文只能新增一个大实验，我会选它。

### D2. 四级数据证据链

1. **Level 0：精确 CP/Tucker sanity check。** 验证实现和可辨识性。
2. **Level 1：解析但 off-model 的受控生成器。** 当前 harmonic、moving envelope 和 residual sweep 属于这一层。
3. **Level 2：独立数值 PDE。** 用 FEM/FDM 求解波动、Helmholtz、扩散或反应扩散方程；训练代码只读取求解结果，不能共享生成公式。
4. **Level 3：公共或真实数据。** 优先选择同时保留 mesh/geometry、边界条件、source 和多实例的数据；若公共数据缺失这些字段，应明确说明它只能测试补全，不能完整验证几何机制。

下一步最值得自建的是多障碍物/多边界的 wave 或 Helmholtz 数据集。保存字段至少包括 mesh/coordinates、离散算子、材料系数、源点、边界条件、时间/频率坐标、完整真值以及独立生成的 observation masks。数据生成器和模型代码必须分离。

### D3. 从 entry-random 扩展到有物理意义的 mask

仅用随机条目会高估实际传感器的空间覆盖。建议统一实现：

- entry-random；
- 固定空间传感器、完整或稀疏时间轨迹；
- fiber missing：整条 mode fiber 缺失；
- sector/gap missing：连续空间区域完全不可见；
- boundary-biased / geometry-biased sensing；
- 完整时间片或完整几何实例缺失。

同时报告 entry ratio 和传感器数量。例如“1% entries”可能来自大量随机点，也可能只来自 4 个传感器，两者统计难度不同。几何先验最有价值的场景很可能不是 entry-random，而是连续缺口和跨几何迁移。

### D4. 系统测试几何误差

加入边界位置扰动、图边删除/添加、算子系数误差、源位置误差和材料参数误差。每项比较 oracle geometry、estimated geometry、flat/no geometry 和 adversarially wrong geometry。这样才能区分“需要精确几何的 oracle 方法”和“对真实几何误差有容忍度的方法”。

## 5. 实验与 baseline 方向

### E1. baseline 应承担因果角色

| baseline | 回答的问题 |
|---|---|
| mean / interpolation | 是否连最简单平滑都没有超过？ |
| discrete CP/Tucker | 优势来自连续表示还是仅来自低秩？ |
| flat Bayesian CP/Tucker | 优势是否来自几何算子先验？ |
| wrong-geometry model | 方法是否真的使用了正确几何？ |
| oracle-rank tensor | 失败是秩选择还是模型格式？ |
| geometry-only GP | 张量共享是否比单独平滑更有效？ |
| raw F-INR / monolithic INR | 显式张量是否优于联合函数拟合？ |
| IP-NF | 相位/传播归纳偏置是否优于隐式物理坐标？ |
| proposed without UQ/gates/residual | 每个新组件是否必要？ |

至少同时做 parameter-matched 和 compute-matched 比较，并报告训练时间、峰值显存、参数量/有效自由度。对外部 baseline，首选作者实现或严格按论文配置复现；不能只用明显弱化的自写版本代表整个方法族。

### E2. rank 与容量公平性

所有张量方法至少给 oracle rank、统一 rank sweep 和验证集选择 rank 三种视角。INR 不应只匹配名义参数量，还应匹配训练预算。Bayesian 方法另报告先验超参数选择使用了多少观测，避免把额外 validation 信息算成免费资源。

### E3. 统计协议

- pilot seed 用于调试，selection seed 用于选择配置，final seed 一次性确认；三者不能混用。
- 主要结论至少 10 个新 seed，报告 mean、standard error、median 和每个 seed 的 paired difference。
- 每篇论文预先指定一个 primary metric；其他指标作为机制或诊断，避免在多个指标间挑最有利者。
- 多观测率 phase diagram 主要用于描述边界；若逐格声称显著性，应使用成对检验和多重比较校正。
- test mask 永远不参与 early stopping、rank selection、尺度校准或 geometry learning。

## 6. Formulation 与论文故事的三个选择

### 方案 I：保持两篇论文，强化各自最短主线（推荐）

- Paper A：**Operator-prior Bayesian tensor factorization with calibrated uncertainty**。主方法升级为 CP/Tucker 统一形式，重点是算子谱先验、结构化后验和低观测率 UQ。
- Paper B：**Geometry/phase-aligned neural tensor factorization across domains**。重点是跨几何传播坐标、相位—包络显式因子以及跨分辨率/跨形状泛化。

两篇共享数据接口、mask taxonomy、phase diagram 和一套 baseline discipline，但不强求同一优化器或应用。优点是每篇贡献可验证、叙事清楚；缺点是需要认真解释边界。

### 方案 II：合成统一方法论文

把传统算子先验、Bayesian posterior 和神经连续因子写成一个统一的 geometry-aware tensor family，并用 approximation–estimation tradeoff 解释所有结果。理论上完整，但方法容易过宽：贝叶斯推断、神经表示、相位物理和多几何迁移会同时竞争篇幅。除非后续发现 A/B 能共享同一个后验与训练代码，否则不建议现在合并。

### 方案 III：以“何时几何张量有效”为机制/benchmark 论文

如果 A1 或 B1 的绝对性能提升有限，但二维 phase diagram 稳定，可以把主贡献改为：一个控制张量可分性、几何失配和观测稀疏度的基准，以及两类代表性模型。这会比强行宣称普适 SOTA 更可信，但方法创新权重会下降。

## 7. 我建议的三轮迭代

### 第 1 轮：只解决最关键表示缺口

- 实现 A1 的小核心 operator Bayesian Tucker。
- 实现 B1 的 phase-envelope rank \(Q\) 扫描。
- 同步建立 D1 的小型 phase diagram；先用 3 个 pilot seed，不追求最终统计。

这一轮不加入 learned geometry、复杂 ARD 或大 residual network。目标是判断两条主线是否都有一个最小、稳定的表示扩展。

### 第 2 轮：确认机制和不确定性

- 对胜出的 A/B 配置跑独立的 10-seed final confirmation。
- A 侧加入规范固定的 block posterior，并做 coverage-width 曲线。
- B 侧对 phase-envelope 做 correct/wrong geometry、参数匹配和残差能量消融。
- mask 扩展到固定传感器和连续缺口。

### 第 3 轮：切断“数据生成器同源”的质疑

- 用独立 PDE solver 生成多几何 wave/Helmholtz 数据。
- 冻结前两轮确定的模型和主要超参数，只允许很小的公开调整范围。
- 若独立 PDE 结果仍为正，再投入 learned metric、跨网格 correspondence 和公开大数据适配。

## 8. 建议审阅的三个决策点

我的当前推荐排序是：

1. **共享优先级：先做二维 phase diagram。** 它最能把已有正负结果变成统一而可信的科学结论。
2. **Paper A：先做 Bayesian Tucker，再做复杂后验。** 当前最大负信号是格式失配，不是区间校准。
3. **Paper B：先做显式 phase-envelope tensor，再考虑自由 residual。** 它直接针对移动包络失败，同时最大限度保留张量故事。

需要重点判断的是：
