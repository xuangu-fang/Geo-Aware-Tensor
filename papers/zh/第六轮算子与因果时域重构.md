# 第六轮迭代：算子图谱与因果时域重构

> **2026-08-13 复核更正：**本轮把 early-40 的小幅 paired 差异称为外部正信号是
> 错误判断。所有方法 NRMSE≈1；paired 只解释约 1.64% 方差，相对 persistence 的
> MSE skill 约 1.96%。该任务现已改判 REJECTED，以下数值保留为实验历史而非正证据。

## 1. Paper A：完整 2D graph mode

第五轮指出 x/y 轴向平均会抹去 maze topology。本轮直接在 64×64 material field
上构造完整二维加权 graph Laplacian，并把 tensor mode 重写为
`instance/source × time × geometry-specific graph spectral mode`。

六个数量级的材料反差使图近乎不连通，普通 ARPACK `which=SM` 在 40,961 次迭代
后 0/16 收敛。改用位于 PSD spectrum 外的负微移 shift-invert 后，10 个 geometry、
64 modes 的 basis 在 10.8 秒内完成，最大 eigen residual `1.12e-6`，算子对称误差 0。
这解决了数值问题，也保留了二维拓扑。

结果仍是负的：full-material graph correct Tucker 约 1.000，与 wrong/CP 无实质
差别，posterior core precision 到 `1e5`；通道子图 correct Tucker 1.011，反而不如
wrong 1.001。最低全局 eigenmodes 优先描述近断连材料区或过平滑通道，无法表达
局部高频反射。因此该版本 **REJECTED**。下一候选是 operator bandpass/graph
wavelet Tucker；继续加 lowest modes 或 rank 不符合本项目的最小核心改造原则。

## 2. Paper B：early causal horizon

201 个未来时刻的长时域 formulation 中 correct/wrong path 几乎相同。保持模型、
训练步数和 1% mask 不变，只把目标冻结为前 40 个 future frames 后，seed 0 的
validation NRMSE 变为 paired 0.9745、wrong 0.9900、neural CP 0.9785、joint INR
0.9879。早期传播尚未被多次反射完全混合，geometry path coordinate 因而可辨认。

按预注册纪律冻结最低的 1%、horizon=40、500 steps，不再看 validation 调整。

## 3. 当前审稿故事

- Paper A：合成/独立 solver 上 operator Bayesian Tucker 是强主线；The Well 的
  低频 graph negative gate 明确指出 localized operator dictionary 是缺口。
- Paper B：synthetic phase diagram 给出机制证据；The Well early/long horizon 均未
  通过绝对效果门槛，外部有效性仍为空缺。
- 两篇继续共享数据、mask、phase diagram 和 baseline discipline；A 的 Bayesian
  operator posterior 与 B 的 explicit paired functional tensor 不合并为一篇。
